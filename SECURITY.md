# 🔐 Security Policy & Vulnerability Disclosure

We take enterprise infrastructure security seriously. If you discover a vulnerability or potential misconfiguration in these Terraform modules:

1. **Do not disclose publicly** in an open GitHub issue.
2. Email full technical reproduction details to `rushikeshbonde@outlook.com`.
3. Expected initial triage response: **Under 24 hours**.
4. Patch turnaround target: **Under 72 hours for critical/high vulnerabilities**.
